# `secretx` - Classification Marking Macros

## Description

This package provides a set of LaTeX macros for marking paragraphs in a
document with a leading string and setting the header and footer of each
page based on the marking(s) on the page.  This is the spiritual
successor to the `secret.sty` package with the added benefits of
providing:

-   Environments to mark large sections of text
-   Environments for placing figures or tables in a box with a header
    in the corners.
-   `Beamer` headline and footline definitions
